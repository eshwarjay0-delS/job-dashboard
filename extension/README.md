# MarketFit — AI Resume Tailor Extension

A Chrome extension that tailors your resume to any job description in under 30 seconds.

## Setup

### 1. Generate icons (one-time)

```bash
cd job-dashboard
npm install sharp --save-dev
node extension/generate-icons.js
```

### 2. Load in Chrome

1. Open **chrome://extensions**
2. Toggle **Developer mode** ON (top right)
3. Click **Load unpacked**
4. Select the `extension/` folder inside your job-dashboard repo
5. The MarketFit icon appears in your toolbar

### 3. Start the MarketFit app

```bash
npm run dev
```

The extension connects to `http://localhost:3000` by default.

---

## How to use

1. **Browse to a job posting** (LinkedIn, Indeed, Glassdoor, etc.)
2. **Click the MarketFit icon** in your toolbar
3. Click **⚡ Grab from page** — the JD is auto-extracted
4. Click **✨ Tailor & Download Resume** — takes ~15–30 seconds
5. Download as **PDF** or **Word (.docx)**

---

## Features

- ✅ **Quick Fill** — one click fills name, email, phone, location, LinkedIn, GitHub, and portfolio on any application form, straight from your resume (no tailoring needed)
- ✅ **ATS-aware autofill** — dedicated field maps for Greenhouse, Lever, Workday, Ashby, SmartRecruiters, BambooHR, and Jobvite, plus a generic pass for everything else. Works alongside Simplify (fills what it misses)
- ✅ Auto-extracts JD from LinkedIn, Indeed, Glassdoor, ZipRecruiter, Dice, Greenhouse, Lever, Workday
- ✅ Keyword auto-match — picks the best resume from your library
- ✅ AI tailoring via Claude — 90–95% keyword match target, under 20s
- ✅ Match score (before → after)
- ✅ PDF and .docx download
- ✅ Open result in the full dashboard
- ✅ Floating button on job pages — "Tailor Resume" on listings, "Autofill Form" on applications

## How autofill works

1. Open any job application form (Greenhouse, Lever, Workday, etc.)
2. Click the MarketFit icon → **Quick Fill** tab
3. Your profile (read from your newest resume) shows at the top
4. Click **⚡ Fill This Page** — fields fill instantly with a confirmation toast
5. Always review before submitting

After tailoring a resume, the result panel also has **⚡ Auto-fill Application**, which fills the form from that specific tailored resume's contact details.

## Architecture

```
extension/
  manifest.json      — MV3 Chrome extension config
  popup.html         — Self-contained popup UI (dark theme)
  popup.js           — UI logic, calls /api/tailor on localhost
  content.js         — Scrapes job descriptions from job boards
  background.js      — Service worker (minimal relay)
  icons/             — Extension icons (generated by generate-icons.js)
  generate-icons.js  — PNG icon generator (run once)
```

The extension calls the same `/api/tailor` API route that the dashboard uses.
Your resume data never leaves your machine.
