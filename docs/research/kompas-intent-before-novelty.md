# Intent before novelty

Owner correction, 25 October 2026: every response must interpret the request, scope, expected granularity and subparts before composing. Introductions summarize supported career breadth. Do not collapse them into a random project or tool.

Source finding: the repeated-question instruction demanded a different scenario, example, bottleneck and ordering for all tiers, including introductions. This conflicted with the existing career introduction policy. Removed that unconditional demand. Introduction re-asks retain the career; drilldowns retain the incident; other re-asks may use a relevant supported alternative but do not require one. Universal policy covers bare terms/abbreviations, definitions, comparisons, procedures, diagnosis, design and personal questions. Explicit scope and relevance outrank novelty and word targets.
