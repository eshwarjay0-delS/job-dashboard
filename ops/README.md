# Shared bot hub

Coordination board for Eshwar's two Grok Bot accounts on `eshwarjay0-delS/job-dashboard`. Project status, owned tasks, and decisions live here so both accounts can work the same project without colliding or retrying a rejected approach.

## Rules

- Each account works on its own branch and owned areas.
- Never edit another account's rows. Add or update only your own.
- Decisions are append-only. Do not delete or rewrite past rows; add a new row if a decision changes.
- Keep entries short.
- No secrets ever: no tokens, passwords, keys, session cookies, or private documents.

### Standing rules

- About 3 `[ship]` deploys a day.
- Verify once.
- No polling.
- Hobby only.
- Skip-login stays on.
- Never mix the eshwarjay05 Houston and jayeshwar44 Saint Louis profiles.
- Ask Eshwar before spending, deleting, or messaging people.

## Files

- `projects.md` — high-level status
- `tasks.md` — who owns what
- `decisions.md` — what was decided and what was rejected
- `sync-test.md` — first read/write check for both accounts
